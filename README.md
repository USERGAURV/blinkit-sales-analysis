# 🛒 Blinkit Sales Analysis

This project contains an end-to-end data analysis of Blinkit (formerly Grofers) grocery sales data. The goal is to understand sales trends, customer behavior, and product performance to drive business insights.

### 📁 Files in this Repository
- blinkit analysis (1).ipynb - Main Jupyter Notebook with EDA, Cleaning and Visualizations
- Swiggy PPT.pptx - Presentation file with key insights and business recommendations
- README.md - Project documentation

### 🎯 Objectives
- To perform Exploratory Data Analysis (EDA) on Blinkit sales dataset
- To identify top-selling product categories
- To analyze sales trends by outlet location, type, and size
- To find customer buying patterns

### 🛠️ Tech Stack Used
- *Language:* Python
- *Libraries:* Pandas, NumPy, Matplotlib, Seaborn
- *Tools:* Jupyter Notebook, GitHub
- *Concepts:* Data Cleaning, EDA, Data Visualization

### 📊 Key Insights
- Analyzed sales distribution across different outlet types
- Found correlation between product visibility and sales
- Identified low-performing outlets and product categories
- Recommended strategies to increase revenue

### 🚀 How to Run This Project
1. Clone the repo: git clone https://github.com/USERGAURV/blinkit-sales-analysis.git
2. Open blinkit analysis (1).ipynb in Jupyter Notebook / VS Code
3. Install required libraries: pip install pandas numpy matplotlib seaborn
